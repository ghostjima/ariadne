# A smoke run, not a result

This is the summary the bench wrote for a small run made to check the
bench itself: two seeds a set, two repeats, the script, the baseline and
the smallest model, on a machine other test suites were using at the
time (load average 6.7 at the start). With four runs a set its shares
say nothing about the model, and its latencies carry the other work on
the machine. It is kept to show what a summary holds and that the stamps
are in it. The command:

```bash
node scripts/bench.mjs --out <dir> --agents scripted,naive,qwen3:1.7b --seeds 2 --repeats 2 --stops 3 --langs ru,en
```

What follows is `SUMMARY.md` as written, with its title one level down.
